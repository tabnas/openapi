(a) `$ref` as a lexical (token) operator on jsonic+expr
    prefix op src "$ref"   { $ref: '#/x' }      -> ERROR unexpected
    prefix op src "$ref"   $ref '#/x'           -> ["$ref","#/x"]
    prefix op src "$ref"   { '$ref': '#/x' }    -> {"$ref":"#/x"}
    infix op src "$ref"    { $ref: '#/x' }      -> ERROR unexpected
    infix op src "$ref"    $ref '#/x'           -> ERROR unexpected
    infix op src "$ref"    { '$ref': '#/x' }    -> {"$ref":"#/x"}
